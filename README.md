# 尿酸监测猫 · 网页版

由 Mac 桌面版独立移植的浏览器小工具。原桌面项目和健康记录保持原样。

- 尿酸、饮水、运动和体重独立录入，支持补录、编辑、删除、历史和 7/30/90 天趋势。
- IndexedDB 保存在访问者当前浏览器中，无健康记录服务器、账号系统或跨设备同步。不同用户的浏览器数据互相隔离。
- 支持原桌面版 JSON 备份的导入与导出、CSV 下载。恢复前校验和确认；读写事务保留上一版本，失败不提交。
- 浏览器关闭或数据被清除后无法后台提醒；只有页面保持可见时提醒，默认关闭。
- 支持手机布局。小猫图像沿用原项目素材。

## 开发

```sh
npm ci
npm run dev
npm run build
```

本机 Node 位于 `~/.local/share/uric-cat-toolchain/node-v24.19.0-darwin-arm64/bin`，需要时加入当前终端 PATH。网站静态输出为 `dist/`；Sites 配置在 `.openai/hosting.json`。
